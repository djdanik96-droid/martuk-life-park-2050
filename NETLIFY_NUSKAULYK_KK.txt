MARTUK LIFE PARK 2050 — Netlify арқылы жариялау

МАҢЫЗДЫ: Бұл архив бастапқы код. Оны Netlify Drop-қа сүйреп апару — дайын сайтқа тең емес. Netlify GitHub арқылы npm build жүргізуі қажет.

1) ZIP архивті компьютерде ашыңыз.
2) github.com сайтына кіріп, New repository жасаңыз (мысалы, martuk-life-park-2050). Құпия/жария рұқсатын өзіңіз таңдаңыз.
3) Repository ішінен Add file > Upload files арқылы архивтің ішіндегі файлдар мен бумаларды (src, public, scripts және т.б.) жүктеңіз. ZIP-тің өзін ғана жүктемеңіз. Commit changes басыңыз.
4) app.netlify.com > Add new project > Import an existing project > GitHub тармағын ашып, репозиторийді таңдаңыз.
5) Build command: npm install --no-audit --no-fund && npm run build; Publish directory: dist. Құрамдағы netlify.toml мұны автоматты баптайды.
6) Deploy site басыңыз. Build log-ты тексеріңіз. Қате болса мәтінін немесе скриншотын жіберіңіз.
7) Жарияланған HTTPS сілтемені ашып, барлық бөлімді тексеріңіз.
8) Офлайн тексеру: сайтты интернетпен толық жүктеңіз; PWA ресурстары сақталғанын күтіңіз; желіні өшіріп, сол адреске қайта кіріңіз. 3D, SMART PARK, маршруттар жұмыс істеуі тиіс. Бұл қадамды нақты жасау қажет.

Ескерту: бұл ортада npm тәуелділіктерін орнату мүмкін болмады, сондықтан build-тің сәтті өтетіні әлі расталған жоқ. Netlify логтары бойынша қосымша түзету қажет болуы мүмкін.
